# WebdriverIO Tests

A small test automation project created for practicing end-to-end testing with the [WebdriverIO](https://webdriver.io/) framework.

## Installation

### Prerequisites
- Node.js

### Setup

```bash
git clone https://github.com/ommagatto/webdriverio-tests.git
cd webdriverio-tests
npm install
```

### Run tests

```bash
npm run wdio
```
